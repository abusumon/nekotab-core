Usage: {% include "ads/in_feed.html" with feed_selector="#mlist" item_selector=".mrow" %} Params: feed_selector — CSS selector for the list container (required) item_selector — CSS selector for one item within it (required) feed_slot — slot id; defaults to adsense_slot_content first_after — items before the first unit (default 3) every — items between subsequent units (default 6) The container is re-rendered wholesale on every search/filter/page change, which wipes the injected units, so an observer re-injects after each redraw. That is also the hazard: a reader flicking through filters would otherwise fire a fresh batch of ad requests per keystroke, which is precisely the pattern AdSense treats as invalid traffic.
