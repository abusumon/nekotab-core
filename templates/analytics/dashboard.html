{% comment %} Admin overview. Design rules this page follows, each fixing a specific failure of the version it replaces: * Every headline number carries a prior-period comparison of equal length. A bare total answers "how many" but not "is that good", which is the question you open an admin dashboard with. * Deltas pair an arrow glyph with the sign — never colour alone, which is invisible to a meaningful share of readers and dies in print. * One accent hue. Traffic and signups are each a single series, so they need no legend and no palette; colour here carries state, not identity. Ranked lists encode magnitude as bar *length* at constant colour, rather than shading bars darker-where-bigger (that would double-encode length as hue and spend the only free channel on information already shown). * Table figures use tabular numerals so columns align; large standalone figures use proportional ones, where equal-width digits read loose. * Gridlines are solid hairlines, never dashed — dashing reads as "threshold" when it is just a grid. * Both charts ship a crosshair tooltip *and* a table view, so no value is reachable only by hovering. * No emoji, no gradient text, no drop shadows on data. Spacing and hairlines do the separating. Surfaces validated with the skill's checker against #141414: all six checks pass (band, chroma, CVD, normal-vision, contrast). Self-contained like its sibling analytics pages: owns its and renders its own messages, since it extends no base carrying the message framework.
